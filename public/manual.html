1. 프로그램 소개

픽미팅은 회사 구성원들이 별도 외부 서비스 가입 없이 사내에서 빠르고 안전하게 화상회의를 진행할 수 있도록 만든 전용 프로그램입니다.

주요 기능

  • 🎤
    음성 회의P2P 방식으로 다수의 참가자가 동시에 대화 가능합니다.
  • 🖥️
    화면 공유전체 화면 또는 특정 창을 선택해서 공유할 수 있습니다.
  • 💬
    실시간 채팅 · 파일 공유텍스트와 파일을 P2P로 주고받습니다.
  • 🔊
    발언자 자동 강조말하고 있는 사람의 타일에 청록 테두리가 표시됩니다.
  • 🎧
    듣기 전용 모드마이크가 없는 PC에서도 채팅과 듣기로 참여 가능합니다.
  • 📌
    저장된 회의 · 최근 회의자주 사용하는 회의방을 저장해 두고 빠르게 입장합니다.
  • 🔄
    자동 업데이트새 버전이 출시되면 앱이 알아서 다운로드 및 설치합니다.

시스템 요구사항

운영체제Windows 10 이상 (64bit)
메모리최소 2GB, 권장 4GB
인터넷유선/무선 모두 가능 (최소 1Mbps 이상 권장)
마이크내장 마이크 또는 USB/3.5mm 외장 마이크 (없어도 듣기 전용 모드로 입장 가능)
스피커스피커 또는 헤드폰

2. 설치 및 첫 실행

  1. 회사에서 받은 PikMeeting-Setup-X.X.X.exe 파일을 더블클릭합니다.
  2. Windows SmartScreen 경고가 표시되면 "추가 정보" → "실행"을 차례로 클릭합니다.
  3. 설치 마법사 없이 자동으로 설치되고 프로그램이 실행됩니다.
  4. 바탕화면과 시작 메뉴에 "픽미팅" 단축 아이콘이 생성됩니다.
SmartScreen 경고에 대하여
회사 전용 프로그램이라 코드 서명 인증서를 별도로 적용하지 않았습니다. 회사 PC가 아닌 곳에서 다운로드한 게 아닌 한 안전합니다.

4. 회의 만들기 · 참가 · 저장

새 회의 만들기

  1. 이름이 입력되어 있는지 확인합니다.
  2. "새 회의 만들기" 아래 칸에 코드를 입력하거나 비워둡니다. 비워두면 랜덤 6자리 코드가 자동 생성됩니다.
  3. 코드 규칙: 영문 대문자 + 숫자, 4~10자 (예: WEEKLY, DAILY2, ABC123)
  4. 만들기 버튼 클릭 → 즉시 회의방 입장.
  5. 회의 코드를 다른 참가자에게 메신저/이메일로 공유합니다.

코드로 참가

  1. 주최자에게 받은 회의 코드를 "코드로 참가" 칸에 입력합니다.
  2. 참가 버튼 클릭 → 즉시 회의방 입장.

최근 회의 · 저장된 회의 차이

목록 자동 vs 수동 표시 정보
최근 회의 자동 (회의 입장 시 기록) 이름(있으면) + 코드, 참가자 수 미표시
저장된 회의 수동 (+ 추가 또는 📌 클릭) 이름 + 코드, 현재 참가자 수 실시간 표시
💡 활용 예시
매주 정기적으로 하는 회의(주간회의, 일일 스탠드업 등) → 저장된 회의에 추가해서 한 클릭 입장.
일회성 회의 → 최근 회의에 자동 기록되어 같은 날 다시 들어가기 쉬움.

최근 회의를 저장된 회의로 승격

최근 회의 카드 우측의 📌 버튼을 누르면 저장된 회의 목록으로 이동합니다. 최근 회의에서는 자동으로 삭제됩니다.

회의방의 유지

참가자가 모두 나가도 회의 코드는 그대로 유지됩니다. 같은 코드로 다시 입장하면 같은 회의방으로 들어갑니다.

확대 상태에서는 나머지 참가자 타일이 화면 우측에 세로로 정렬되어 메인 영역을 가리지 않습니다.

공유 화면 확대/축소 (줌)

공유 화면이나 비디오를 확대했을 때 다음 방법으로 추가 줌 가능합니다:

  • 마우스 휠 위/아래 — 부드러운 확대/축소
  • 우측 하단 컨트롤 — − 축소, 100% 원본, + 확대
  • 확대된 상태에서 마우스 드래그 — 보이는 영역 이동 (팬)
  • 최대 5배 확대까지 가능. 다이캐스팅 도면이나 보고서 일부분 집중 확인할 때 유용.

10. 자동 업데이트

새 버전이 출시되면 앱이 자동으로 다운로드하여 적용합니다. 사용자의 별도 조작이 필요 없습니다.

각 단계 설명

  1. 앱 실행 → 3초 후 백그라운드에서 새 버전 자동 확인.
  2. 새 버전 발견 시 자동 다운로드 시작 (보통 5~10MB 차분 업데이트).
  3. 다운로드 완료 후 청록색 "준비 완료" 배너 표시.
  4. "지금 적용" 클릭 → 즉시 앱 재시작, 새 버전 적용.
  5. "나중에" 선택 → 다음 종료 시 자동으로 적용.

설정값은 그대로 유지됩니다

11. 문제 해결

마이크를 찾을 수 없다고 나옵니다

가장 흔한 원인은 Windows 마이크 권한이 차단된 경우입니다.

  1. 에러 화면의 "Windows 마이크 설정 열기" 버튼을 클릭합니다.
  2. 다음 항목이 모두 켜짐 상태인지 확인합니다:
    • 마이크 액세스
    • 앱에서 마이크에 액세스하도록 허용
    • 데스크톱 앱이 마이크에 액세스하도록 허용 ← 자주 꺼져 있음
  3. 설정 후 앱으로 돌아와 "다시 시도"를 클릭합니다.

마이크가 다른 프로그램에서 사용 중이라고 나옵니다

다른 화상회의 앱(Zoom, Teams, Discord 등)이 마이크를 점유하고 있을 수 있습니다. 다른 앱을 종료한 후 다시 시도해 주세요.

상대방 음성이 들리지 않습니다

  • 오디오 설정에서 올바른 스피커가 선택되어 있는지 확인합니다.
  • Windows 시스템 볼륨이 음소거되어 있지 않은지 확인합니다.
  • 상대방의 음소거 상태 (빨간 🔇 아이콘)를 확인합니다.

화면 공유가 시작되지 않습니다

Windows 화면 캡처 권한이 필요합니다. 화면 공유 클릭 시 Windows가 권한을 묻는 창을 띄우면 허용해 주세요.

파일 전송이 멈춥니다

  • 파일 크기가 200 MB를 넘는지 확인 (최대 200 MB).
  • 받는 사람이 회의에서 나갔는지 확인.
  • 네트워크 상태 불안정 시 전송이 느려질 수 있습니다.

회의 연결이 자주 끊깁니다

  • 유선 인터넷이 무선보다 안정적입니다.
  • VPN이나 회사 방화벽 정책이 WebRTC 통신을 막을 수 있습니다.
  • 참가자가 많을수록 (6명 이상) 본인의 인터넷 대역폭이 더 필요합니다.

12. 자주 묻는 질문 (FAQ)

회의는 동시에 몇 명까지 참여할 수 있나요?

기술적으로는 약 6~8명까지 무리 없이 동작합니다. P2P 방식이라 참가자가 늘어날수록 각자의 네트워크 대역폭이 더 필요해집니다.

회의 내용이 녹음되거나 서버에 저장되나요?

아닙니다. 모든 통신은 P2P 방식으로 참가자 PC 사이에서만 오가며, 시그널링 서버는 단순히 연결을 중개할 뿐 음성/영상/채팅 내용을 받지 않습니다. 파일 전송도 마찬가지입니다.

회사 외부에서도 사용할 수 있나요?

네, 인터넷이 연결된 곳이면 어디서나 사용 가능합니다. 회의 코드만 알고 있으면 됩니다.

회의 코드가 노출되면 누구나 입장할 수 있나요?

네, 코드를 아는 사람은 누구나 입장 가능합니다. 민감한 회의는 외부에 노출되지 않도록 주의해 주세요. 회의별로 코드를 다르게 정하는 것도 좋은 방법입니다.

화상(비디오/카메라) 기능은 없나요?

현재는 음성과 화면 공유만 지원합니다. 향후 업데이트로 카메라 기능이 추가될 수 있습니다.

파일을 보낼 때 받는 사람이 회의에 없으면 어떻게 되나요?

P2P 방식이므로 회의에 들어와 있는 참가자에게만 전송됩니다. 나중에 들어온 사람은 받지 못합니다. 중요한 파일은 회의 시작 후에 보내거나 미리 메신저로 전달해 주세요.

앱이 갑자기 종료되거나 회의가 끊깁니다

인터넷 연결을 먼저 확인해 주세요. 그래도 같은 문제가 반복되면 앱을 완전히 종료한 후 다시 실행해 보세요. 그래도 해결되지 않으면 개발자에게 문의해 주세요.

설치한 PC를 바꾸려면 어떻게 하나요?

기존 PC에서 제어판을 통해 프로그램을 제거한 후, 새 PC에 인스톨러를 실행하면 됩니다. 단, 저장된 회의 목록과 이름은 이전되지 않으므로 새로 설정해야 합니다.

자동 업데이트가 안 되는 것 같아요

앱 실행 후 3초 뒤에 체크가 시작됩니다. 인터넷이 연결되어 있는지 확인하시고, 좌측 하단의 현재 버전을 확인해 주세요. 만약 최신 버전이 더 높다면 한 번 더 재시작해 보세요.

최근 회의 목록을 지우고 싶어요

각 카드 우측의 ✕ 버튼을 누르면 해당 회의만 목록에서 제거됩니다. (실제 회의방은 그대로 유지)

문제 해결이 되지 않을 때
위 가이드로 해결되지 않는 문제가 있다면 개발 담당자(서정천)에게 다음 정보와 함께 문의해 주세요.
  • 발생한 문제 상황 (가능하면 화면 캡처)
  • 본인 PC의 운영체제 (예: Windows 11)
  • 현재 사용 중인 앱 버전 (좌측 하단 표시)
  • 어떤 동작 후 문제가 발생했는지
