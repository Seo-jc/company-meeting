1. 프로그램 소개

사내 미팅 프로그램은 회사 구성원들이 별도의 외부 서비스 가입 없이 사내에서 빠르고 안전하게 화상회의를 진행할 수 있도록 만든 전용 프로그램입니다.

주요 기능

  • 🎤
    음성 회의P2P 방식으로 다수의 참가자가 동시에 대화 가능합니다.
  • 🖥️
    화면 공유전체 화면 또는 특정 창을 선택해서 공유할 수 있습니다.
  • 💬
    실시간 채팅회의 중에 텍스트 메시지를 주고받을 수 있습니다.
  • 🎧
    듣기 전용 모드마이크가 없는 PC에서도 채팅과 듣기로 참여 가능합니다.
  • 📋
    회의 코드 시스템4~10자리 영문/숫자 코드로 간편하게 입장합니다.
  • 📌
    저장된 미팅자주 사용하는 회의방을 저장해 두고 빠르게 입장할 수 있습니다.
  • 🔄
    자동 업데이트새 버전이 출시되면 앱이 알아서 다운로드 및 설치합니다.

시스템 요구사항

운영체제Windows 10 이상 (64bit)
메모리최소 2GB, 권장 4GB
인터넷유선/무선 모두 가능 (최소 1Mbps 이상 권장)
마이크일반 PC 내장 마이크 또는 USB/3.5mm 외장 마이크
스피커스피커 또는 헤드폰

2. 시작하기

설치

  1. 회사에서 받은 CompanyMeeting-Setup-X.X.X.exe 파일을 더블클릭합니다.
  2. Windows SmartScreen 경고가 표시되면 "추가 정보" → "실행"을 차례로 클릭합니다.
  3. 설치 마법사 안내에 따라 설치 경로를 선택하고 "설치" 버튼을 누릅니다.
  4. 설치가 완료되면 바탕화면과 시작 메뉴에 "사내 회의" 단축 아이콘이 생성됩니다.
SmartScreen 경고에 대하여
회사 전용 프로그램이라 코드 서명 인증서를 별도로 적용하지 않았습니다. 회사 PC가 아닌 곳에서 다운로드한 게 아닌 한 안전합니다.

3. 로비 화면 둘러보기

프로그램을 실행하면 가장 먼저 만나는 화면이 로비입니다. 여기서 회의를 만들거나 참여할 수 있습니다.

로비 화면 구성

  • 🏷️
    회로 기판 스타일 로고화면 상단에 표시됩니다.
  • 📝
    이름 입력란회의에서 다른 참가자에게 표시될 이름을 입력합니다. (마지막 입력 이름은 자동 저장됨)
  • ➕
    새 미팅 만들기 버튼새로운 회의방을 생성합니다. 회의 제목과 코드를 직접 정할 수 있습니다.
  • 🔑
    코드로 참여 버튼다른 사람이 알려준 회의 코드를 입력해서 입장합니다.
  • 📌
    저장된 미팅 목록이전에 저장해 둔 회의들이 표시됩니다. 현재 참가자 수도 실시간으로 확인 가능합니다.
  • 📖
    사용자 메뉴얼 버튼이 PDF 문서를 다시 볼 수 있습니다.

이름 입력

회의에 입장하기 전 화면 상단의 이름 입력란에 본인 이름을 입력합니다. 한 번 입력한 이름은 자동으로 저장되어 다음 실행 시 자동으로 채워집니다.

이름 표시 권장
예: "홍길동", "본사 홍길동", "VINA 김철수" 등 부서/지역을 함께 적으면 다른 참가자가 한눈에 알아볼 수 있어 좋습니다.

4. 회의 참여하기

새 회의 만들기

  1. 로비에서 ➕ 새 미팅 만들기 버튼을 클릭합니다.
  2. 회의 제목을 입력합니다. (예: "본사/VINA 주간회의")
  3. 회의 코드를 입력합니다. (4~10자, 영문 대문자 + 숫자만 가능)
    예: WEEKLY, MORNING1, ABCD123
  4. 만들기 버튼을 클릭하면 즉시 회의방에 입장합니다.
  5. 다른 참가자에게 회의 코드를 알려주면 입장할 수 있습니다.
코드 정하는 팁
모든 사람이 외우기 쉬운 단어로 정하면 좋습니다. 영구적으로 쓸 회의(예: 주간회의)는 WEEKLY 처럼 의미있는 코드로 정해두고 저장해 두세요.

코드로 참여

  1. 로비에서 🔑 코드로 참여 버튼을 클릭합니다.
  2. 주최자에게 받은 회의 코드를 입력합니다.
  3. 참여 버튼을 클릭하면 즉시 회의방에 입장합니다.

저장된 미팅으로 빠르게 입장

자주 사용하는 회의방은 저장해 두면 한 번의 클릭으로 입장할 수 있습니다.

  1. 회의에 한 번 입장하면 자동으로 저장됩니다.
  2. 로비의 저장된 미팅 목록에 표시됩니다.
  3. 제목, 코드, 현재 참가자 수가 함께 표시됩니다.
  4. 녹색 점(●)이 표시되면 현재 누군가 회의에 참가 중이라는 뜻입니다.
  5. 카드를 클릭하면 즉시 그 회의방에 입장합니다.
저장된 미팅의 삭제
저장된 미팅 카드 우측의 ✕ 버튼을 누르면 목록에서 제거할 수 있습니다. 이 동작은 회의 자체를 삭제하는 게 아니라 본인 PC의 빠른 입장 목록에서만 빼는 것입니다.

5. 회의 화면 사용법

회의 화면 구성

  • ⏱
    경과 시간좌측 상단에 현재 시각과 회의 경과 시간이 표시됩니다.
  • 📋
    회의 코드 영역우측 상단에서 회의 코드 확인 및 클립보드 복사가 가능합니다.
  • 👥
    참가자 수현재 회의에 접속한 인원 수가 표시됩니다.
  • 🟦
    참가자 타일각 참가자가 사각형 영역으로 표시됩니다. 음성만 사용 시 이름 첫 글자가 원형 아바타로 표시됩니다.
  • 🎮
    하단 제어 막대음소거, 화면 공유, 채팅, 나가기 버튼이 위치합니다.

음소거 / 음소거 해제

하단의 🎤 음소거 버튼을 클릭하면 본인의 마이크가 음소거됩니다. 다시 클릭하면 해제됩니다.

  • 음소거 시 버튼이 빨간색 🔇으로 바뀝니다.
  • 다른 참가자에게도 본인의 음소거 상태가 표시됩니다.

화면 공유

  1. 하단의 🖥️ 화면 공유 버튼을 클릭합니다.
  2. Windows 화면 선택 창이 뜨면 공유할 화면이나 창을 선택합니다.
  3. 공유 버튼을 누르면 다른 참가자들에게 화면이 표시됩니다.
  4. 공유를 중지하려면 다시 공유 중지 버튼을 클릭합니다.
전체 화면 vs 특정 창 공유
특정 창만 선택하면 알림이나 다른 앱이 화면에 보여도 다른 참가자에게는 노출되지 않습니다. 민감한 정보가 있을 때는 특정 창 공유를 권장합니다.

채팅

하단의 💬 채팅 버튼을 클릭하면 우측에 채팅 패널이 열립니다.

  • 새 메시지가 있는데 채팅이 닫혀 있으면 버튼에 숫자 배지가 표시됩니다.
  • 메시지 입력란에 글을 쓰고 Enter를 누르거나 전송 버튼을 클릭합니다.
  • 채팅 내역은 회의가 진행되는 동안만 유지되며 종료 시 사라집니다.

5. 회의 화면 사용법 (이어서)

회의 코드 공유

  1. 회의 화면 우측 상단의 회의 코드 영역을 클릭합니다.
  2. 코드가 클립보드에 복사되고 일시적으로 "복사됨"으로 표시됩니다.
  3. 메신저, 이메일 등에 붙여넣어 다른 사람에게 전달합니다.

회의 나가기

하단의 빨간색 📞 나가기 버튼을 클릭하면 회의를 종료하고 로비로 돌아갑니다.

회의방 자체는 사라지지 않습니다
마지막 한 명이 나가도 회의 코드는 그대로 유지됩니다. 같은 코드로 다시 입장하면 같은 회의방으로 들어갑니다.

참가자 화면 확대

다른 참가자의 화면(또는 공유된 화면)을 더블클릭하면 그 참가자의 화면이 크게 확대됩니다. 다시 더블클릭하면 원래 상태로 돌아갑니다.

6. 오디오 장치 설정

여러 마이크나 스피커가 연결된 환경에서 사용할 장치를 선택할 수 있습니다.

설정 열기

  1. 회의 화면 하단의 🎤 음소거 버튼 위쪽에 있는 ▲ 화살표를 클릭합니다.
  2. 오디오 설정 팝업이 나타납니다.
  3. 마이크와 스피커 드롭다운에서 사용할 장치를 선택합니다.
  4. 선택은 자동으로 저장되어 다음번 실행 시에도 유지됩니다.
장치 핫스왑 지원
회의 중에도 마이크나 스피커를 바꿀 수 있습니다. 회의가 끊기지 않고 즉시 적용됩니다.

7. 듣기 전용 모드

마이크가 없거나 사용할 수 없는 PC에서도 회의에 참여할 수 있는 모드입니다.

듣기 전용 모드로 입장하기

  1. 일반 방식으로 회의 입장을 시도합니다.
  2. 마이크 관련 에러가 발생하면 에러 화면에서 🎧 마이크 없이 입장 (듣기/채팅만) 버튼을 클릭합니다.
  3. 회의방에 입장하며, 상단에 청록색 안내 배너가 표시됩니다.

듣기 전용 모드에서 가능한 것

  • ✅ 다른 참가자의 음성 듣기
  • ✅ 다른 참가자의 화면 공유 보기
  • ✅ 본인의 화면 공유 (마이크와 무관)
  • ✅ 채팅 송수신
  • ❌ 본인 음성 발신 (마이크가 없으므로)

8. 자동 업데이트

새 버전이 출시되면 앱이 자동으로 다운로드하여 적용합니다. 사용자의 별도 조작이 필요 없습니다.

업데이트 동작 흐름

  1. 앱을 실행하면 3초 후 백그라운드에서 새 버전이 있는지 자동 확인합니다.
  2. 새 버전 발견 시 자동으로 차분 다운로드가 시작됩니다 (대부분 5~10MB).
  3. 다운로드가 완료되면 "업데이트 준비 완료" 다이얼로그가 표시됩니다.
  4. "지금 재시작"을 누르면 즉시 새 버전이 적용됩니다.
  5. "나중에"를 선택하면 앱을 다음번에 종료할 때 자동으로 적용됩니다.
설정값은 그대로 유지됩니다
업데이트가 적용되어도 이름, 저장된 미팅 목록, 오디오 장치 선택 등의 설정은 모두 유지됩니다.

현재 버전 확인

화면 좌측 하단에 청록색으로 현재 버전이 표시됩니다.
예: v1.3.0 · 개발자 서정천

9. 문제 해결

마이크를 찾을 수 없다고 나옵니다

가장 흔한 원인은 Windows 마이크 권한이 차단된 경우입니다.

  1. 에러 화면의 "Windows 마이크 설정 열기" 버튼을 클릭합니다.
  2. 다음 항목이 모두 켜짐 상태인지 확인합니다:
    • 마이크 액세스
    • 앱에서 마이크에 액세스하도록 허용
    • 데스크톱 앱이 마이크에 액세스하도록 허용 ← 자주 꺼져 있음
  3. 설정 후 앱으로 돌아와 "다시 시도"를 클릭합니다.

마이크가 다른 프로그램에서 사용 중이라고 나옵니다

다른 화상회의 앱(Zoom, Teams, Discord 등)이 마이크를 점유하고 있을 수 있습니다. 다른 앱을 종료한 후 다시 시도해 주세요.

상대방 음성이 들리지 않습니다

  • 오디오 설정에서 올바른 스피커가 선택되어 있는지 확인합니다.
  • Windows 시스템 볼륨이 음소거되어 있지 않은지 확인합니다.
  • 상대방의 음소거 상태(빨간 🔇 아이콘)를 확인합니다.

화면 공유가 시작되지 않습니다

Windows 화면 캡처 권한이 필요합니다. 화면 공유 클릭 시 Windows가 권한을 묻는 창을 띄우면 허용해 주세요.

10. 자주 묻는 질문 (FAQ)

회의는 동시에 몇 명까지 참여할 수 있나요?

기술적으로는 약 6~8명까지 무리 없이 동작합니다. P2P 방식이라 참가자가 늘어날수록 각자의 네트워크 대역폭이 더 필요해집니다. 일반적인 사내 회의 규모에서는 충분합니다.

회의 내용이 녹음되거나 저장되나요?

아닙니다. 본 프로그램은 녹음/녹화 기능을 제공하지 않습니다. 모든 통신은 P2P 방식으로 참가자 PC 사이에서만 오갑니다.

회사 외부에서도 사용할 수 있나요?

네, 인터넷이 연결된 곳이면 어디서나 사용 가능합니다. 회의 코드만 알고 있으면 됩니다.

회사 외 사람을 초대해도 되나요?

기술적으로 가능하나, 회사 정책에 따라 다릅니다. 사내용 프로그램이므로 회사 정책을 확인해 주세요.

회의 코드가 노출되면 누구나 입장할 수 있나요?

네, 코드를 아는 사람은 누구나 입장 가능합니다. 민감한 회의는 외부에 노출되지 않도록 주의해 주세요. 회의별로 코드를 다르게 정하는 것도 좋은 방법입니다.

화상(비디오) 기능은 없나요?

현재는 음성과 화면 공유만 지원합니다. 향후 업데이트로 카메라 기능이 추가될 수 있습니다.

앱이 갑자기 종료되거나 회의가 끊깁니다

인터넷 연결을 먼저 확인해 주세요. 그래도 같은 문제가 반복되면 앱을 완전히 종료한 후 다시 실행해 보세요. 그래도 해결되지 않으면 개발자에게 문의해 주세요.

설치한 PC를 바꾸려면 어떻게 하나요?

기존 PC에서 제어판을 통해 프로그램을 제거한 후, 새 PC에 인스톨러를 실행하면 됩니다. 단, 저장된 미팅 목록과 이름은 이전되지 않으므로 새로 설정해야 합니다.

자동 업데이트가 안 되는 것 같아요

앱 실행 후 3초 뒤에 체크가 시작됩니다. 인터넷이 연결되어 있는지 확인하시고, 그래도 안 되면 좌측 하단의 현재 버전을 확인해 주세요. 만약 최신 버전이 v1.3.0인데 그보다 낮다면 한 번 더 재시작해 보세요.

문제 해결이 되지 않을 때
위 가이드로 해결되지 않는 문제가 있다면 개발 담당자(서정천)에게 다음 정보와 함께 문의해 주세요.
  • 발생한 문제 상황 (가능하면 화면 캡처)
  • 본인 PC의 운영체제 (예: Windows 11)
  • 현재 사용 중인 앱 버전 (좌측 하단 표시)
  • 어떤 동작 후 문제가 발생했는지
