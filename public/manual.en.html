1. Introduction

PikMeeting is a dedicated in-house program that lets company staff hold fast, secure video meetings internally without signing up for any external service.

Key Features

  • 🎤
    Voice meetingsMultiple participants can talk at the same time over a P2P connection.
  • 🖥️
    Screen sharingShare your entire screen or a specific window of your choice.
  • 💬
    Real-time chat & file sharingExchange text and files directly over P2P.
  • 🔊
    Automatic active speaker highlightA teal border appears around the tile of whoever is currently speaking.
  • 🎧
    Listen-only modeJoin with chat and listening only, even from a PC without a microphone.
  • 📌
    Saved meetings & recent meetingsSave meeting rooms you use often for quick, one-click entry.
  • 🖊️
    Annotation · Recording · MinutesMark up, record, and write together, then save to Excel. (Ch. 10-12)
  • 🔄
    Auto-updateWhen a new version is released, the app downloads and installs it automatically.

System Requirements

Operating SystemWindows 10 or later (64-bit)
Memory2 GB minimum, 4 GB recommended
InternetWired or wireless (1 Mbps or faster recommended)
MicrophoneBuilt-in mic or USB/3.5mm external mic (you can still join in listen-only mode without one)
SpeakerSpeakers or headphones

2. Installation & First Run

  1. Double-click the PikMeeting-Setup-X.X.X.exe file you received from the company.
  2. If a Windows SmartScreen warning appears, click "More info" → "Run anyway" in that order.
  3. The program installs automatically, with no setup wizard, and launches right away.
  4. A "PikMeeting" shortcut icon is created on the desktop and in the Start menu.
About the SmartScreen Warning
Because this is an in-house program, it does not carry a separate code-signing certificate. It is safe as long as you didn't download it from anywhere other than a company PC.

4. Creating, Joining & Saving Meetings

Creating a New Meeting

  1. Make sure your name has been entered.
  2. Under "Create New Meeting," enter a code or leave it blank. If left blank, a random 6-character code is generated automatically.
  3. Code rules: uppercase letters + numbers, 4-10 characters (e.g. WEEKLY, DAILY2, ABC123)
  4. Click the Create button → you enter the meeting room immediately.
  5. Share the meeting code with other participants via messenger or email.

Joining with a Code

  1. Enter the meeting code you received from the host into the "Join with Code" field.
  2. Click the Join button → you enter the meeting room immediately.

Recent Meetings vs. Saved Meetings

List Automatic vs. Manual Information Displayed
Recent Meetings Automatic (recorded when you enter a meeting) Name (if any) + code; participant count not shown
Saved Meetings Manual (via + Add or clicking 📌) Name + code, with current participant count shown in real time
💡 Usage Example
Recurring meetings (weekly meetings, daily stand-ups, etc.) → add them to Saved Meetings for one-click entry.
One-off meetings → automatically recorded in Recent Meetings, making it easy to rejoin the same day.

Promoting a Recent Meeting to Saved

Click the 📌 button on the right side of a recent meeting card to move it to the Saved Meetings list. It's automatically removed from Recent Meetings.

Meeting Room Persistence

Even after all participants leave, the meeting code remains active. Entering the same code again takes you back into the same meeting room.

12. Meeting Minutes (Restore)

  • While you write, the content is kept on your PC automatically (about every 5 seconds). If the internet drops, what you wrote stays here and is merged automatically once you reconnect ("Disconnected" shows at the top meanwhile).
  • If the app closed suddenly or you left by mistake, rejoin with the same meeting code. When "A previous minutes draft is kept on this PC… Restore it?" appears, click Restore previous minutes (or Start fresh).
  • The kept copy is deleted after about 12 hours and does not replace saving as Excel.
  • Deleted an attendee or agenda item by mistake? Click "Undo" within 10 seconds.
The minutes work between participants on v1.13.0 or later; others don't have the 📝 button.

Step-by-step Explanation

  1. App launches → checks for a new version automatically in the background after 3 seconds.
  2. If a new version is found, download starts automatically (typically a 5-10MB differential update).
  3. Once the download finishes, a teal "Ready" banner is displayed.
  4. Click "Apply Now" → the app restarts immediately and applies the new version.
  5. Choose "Later" → the update is applied automatically the next time you close the app.
Seamless updates with no installer wizard, starting from v1.7.6
Previously, clicking "Apply Now" would launch an NSIS installer wizard that required clicking "Next" several times. From v1.7.6 onward, the update installs silently with no wizard, and the new version launches automatically. The hassle of having to click through an installer every time is now gone.
Your settings are preserved
Even after an update is applied, your name, saved meetings, recent meetings, and audio device selection all remain unchanged.

15. Troubleshooting

"Microphone not found" message appears

The most common cause is that Windows microphone permission is blocked.

  1. Click the "Open Windows Microphone Settings" button on the error screen.
  2. Check that all of the following are turned on:
    • Microphone access
    • Let apps access your microphone
    • Let desktop apps access your microphone ← often turned off
  3. After adjusting the settings, return to the app and click "Try Again".

"Microphone is in use by another program" message appears

Another video conferencing app (Zoom, Teams, Discord, etc.) may be holding the microphone. Please close the other app and try again.

I can't hear the other participant's audio

  • Check that the correct speaker is selected in audio settings.
  • Check that the Windows system volume is not muted.
  • Check the other participant's mute status (red 🔇 icon).

Screen sharing won't start

Windows screen-capture permission is required. If Windows shows a permission prompt when you click screen share, please allow it.

File transfer stalls

  • Check whether the file exceeds 200 MB (200 MB maximum).
  • Check whether the recipient has left the meeting.
  • Transfers may slow down if the network connection is unstable.

The meeting connection keeps dropping

  • A wired connection is more stable than wireless.
  • A VPN or company firewall policy may be blocking WebRTC traffic.
  • The more participants there are (6 or more), the more internet bandwidth you'll need.

16. FAQ

How many people can be in a meeting at once?

Technically, up to about 6-8 people works without issues. Since it's P2P, the more participants there are, the more network bandwidth each person needs.

Is the meeting recorded or stored on a server?

Nothing is recorded automatically or stored on a server. Voice, screen, chat and files travel P2P, directly between participants' PCs, and the signaling server merely helps set up the connection without receiving their content. A recording file is saved only on the PC of the person who clicks ⏺️ Record. The minutes are exchanged between attendees in real time and are not stored on the server; only the Excel file you save remains.

Where are recording files and minutes Excel files saved?

By default in the Downloads\PikMeeting folder on your PC, and minutes Excel files go in the 회의록 folder inside it. Click Open folder in the notice that appears after saving to open it right away.

Can it be used outside the company?

Yes, it can be used anywhere with an internet connection. You just need to know the meeting code.

If a meeting code is exposed, can anyone join?

Yes, anyone who knows the code can join. Please be careful not to let the code leak for sensitive meetings. Using a different code for each meeting is also a good practice.

Is there no video (camera) feature?

Currently only audio and screen sharing are supported. Camera support may be added in a future update.

What happens if I send a file but the recipient isn't in the meeting?

Because it's P2P, the file is only delivered to participants currently in the meeting. Anyone who joins later won't receive it. For important files, send them after the meeting has started, or share them beforehand via messenger.

The app closes unexpectedly, or the meeting drops

Please check your internet connection first. If the same problem keeps happening, try closing the app completely and launching it again. If that still doesn't fix it, please contact the developer.

How do I move to a different PC?

Uninstall the program from Control Panel on the current PC, then run the installer on the new PC. Note that your saved meeting list and name are not carried over, so you'll need to set them up again.

Auto-update doesn't seem to be working

The check starts 3 seconds after the app launches. Make sure you're connected to the internet, and check the current version shown at the bottom left. If the latest version is newer, try restarting the app once more.

I want to clear the recent meetings list

Click the ✕ button on the right of each card to remove just that meeting from the list. (The actual meeting room itself is unaffected.)

If the problem isn't resolved
If a problem isn't fixed by the guidance above, please contact the developer (Seo Jeong-Cheon) with the following information.
  • What happened (a screenshot, if possible)
  • Your PC's operating system (e.g. Windows 11)
  • The app version you're currently using (shown at the bottom left)
  • What you were doing right before the problem occurred
